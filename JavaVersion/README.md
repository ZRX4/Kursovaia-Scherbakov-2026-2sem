# Курсовой проект: Техасский Холдем (Java Edition)

Это Java-версия консольного симулятора спортивного Техасского Холдема, созданная в рамках Лабораторной работы №3 (Часть 1).

## Требования
* **JDK 11 или новее** (проверено на JDK 17).
* Проверить наличие: `java -version` и `javac -version`.

## Структура проекта
* `src/` — исходный код (классы `Card`, `Deck`, `Game` и демонстрация).
* `Main.java` — точка входа в программу.

## Сборка и запуск

Откройте терминал в папке `JavaVersion` и выполните:

```bash

chcp 65001 
# Компиляция исходников в папку out
javac -encoding UTF-8 src/*.java -d out

# Запуск программы
java -Dstdout.encoding=UTF-8 -cp out Main
