# Курсовой проект: Консольный симулятор Техасского Холдема

**Студент:** Щербаков Алексей Сергеевич  
**Группа:** Пи-52  
**Дисциплина:** Объектно-ориентированное программирование

## 📌 О проекте
Данный репозиторий содержит реализацию консольного симулятора игры в спортивный Техасский Холдем с интеллектуальными агентами-соперниками. 

Проект разрабатывался в рамках курса ООП и охватывает следующие темы:
* Проектирование классов предметной области (Карта, Колода, Игра).
* Реализация связей **композиции** и **агрегации**.
* Управление памятью: от ручного (`new`/`delete`) до использования **умных указателей** (`std::unique_ptr`, `std::shared_ptr`, `std::weak_ptr`).
* Перенос объектной модели на язык с управляемой памятью (**Java**), работа со сборщиком мусора и `AutoCloseable`.

## 📂 Структура репозитория
Проект разделен на две независимые реализации одной и той же логики:

* 📁 **`CppVersion/`** — реализация проекта на языке **C++ (стандарт C++17)**.
* 📁 **`JavaVersion/`** — реализация проекта на языке **Java (JDK 11+)**.

## 🚀 Сборка и запуск

### C++ (папка `CppVersion`)
Для сборки потребуется компилятор с поддержкой C++17 (например, `g++` / MinGW).

```bash
# Переход в папку
cd CppVersion

# Компиляция проекта
g++ -std=c++17 -Wall -Wextra *.cpp -o holdem_cpp

# Запуск
./holdem_cpp
```

### Java (папка `JavaVersion`)
Для сборки потребуется компилятор с поддержкой C++17 (например, `g++` / MinGW).

```bash
# Переход в папку
cd JavaVersion

# Компиляция проекта
javac *.java

# Запуск
java Main
```
